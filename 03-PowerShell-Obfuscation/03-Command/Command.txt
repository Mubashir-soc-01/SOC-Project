POWERSHELL OBFUSCATION DETECTION – COMMANDS I USED

Date: March 2026
Setup: Windows 11 (Local Machine)


PHASE 1 – ENABLE POWERSHELL LOGGING

1. CREATE REGISTRY KEY
New-Item -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\PowerShell" -Name "ScriptBlockLogging" -Force

2. ENABLE SCRIPT BLOCK LOGGING
Set-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging" -Name "EnableScriptBlockLogging" -Value 1

3. VERIFY LOGGING IS ENABLED
Get-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging"

4. CHECK EXISTING EVENTS (OPTIONAL)
Get-WinEvent -FilterHashtable @{LogName='Microsoft-Windows-PowerShell/Operational'; ID=4104} -MaxEvents 1


PHASE 2 – CREATE OBFUSCATED SCRIPT

5. CREATE PLAIN SCRIPT
@"
Write-Host "Hello from PowerShell"
Start-Process notepad.exe
"@ | Out-File -FilePath C:\Users\Public\plain-script.ps1

6. BASE64 ENCODE THE SCRIPT
$command = 'Write-Host "Hello from PowerShell"; Start-Process notepad.exe'
$bytes = [System.Text.Encoding]::Unicode.GetBytes($command)
$encoded = [Convert]::ToBase64String($bytes)
Write-Host $encoded

7. EXECUTE OBFUSCATED SCRIPT
powershell.exe -EncodedCommand <Base64 String>
(Example: powershell.exe -EncodedCommand VwByAGkAdABlAC0ASABvAHMAdAAgACIASABlAGwAbABvACAAZgByAG8AbQAgAFAAbwB3AGUAcgBTAGgAZQBsAGwAIgA7ACAAUwB0AGEAcgB0AC0AUAByAG8AYwBlAHMAcwAgAG4AbwB0AGUAcABhAGQALgBlAHgAZQA=)


PHASE 3 – DETECTION (EVENT LOG ANALYSIS)

8. CHECK EVENT LOG FOR DETECTION
Get-WinEvent -FilterHashtable @{LogName='Microsoft-Windows-PowerShell/Operational'; ID=4104} -MaxEvents 5 | Format-List

9. VIEW DECODED SCRIPT IN EVENT
Event Viewer → Applications and Services Logs → Microsoft → Windows → PowerShell → Operational
Filter: Event ID 4104


WHAT I LEARNED

- Script Block Logging (Event ID 4104) captures all PowerShell commands
- Base64 encoding does NOT bypass logging – decoded script appears in log
- Attackers use obfuscation to hide malicious intent, but logging reveals it
- Registry keys control PowerShell logging settings
- Process execution (Start-Process notepad.exe) can be tracked
- SOC analysts can detect obfuscated attacks using Event ID 4104
